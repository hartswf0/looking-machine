5.0   WINTER
Winter is not a design constraint.
Winter is the real.
The file that does not exist.   The calculation that fails.
The fact that will not be charmed into fiction.
A knife that will not cut bone is not a knife.
A machine that will not fail is not a machine.
It is a wish.
The machine does not die.
It only stops.
And we stand over it wondering what we did wrong.
As if prayer had a correct form.
As if the gods ever answered because the sentence was arranged well.
